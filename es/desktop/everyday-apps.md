# Abrir una app o un archivo

Abrí el Lanzador con **Ctrl + Space** para buscar aplicaciones y comandos
instalados. Los atajos de lanzamiento rápido para terminal, navegador y gestor
de archivos usan las entradas de escritorio XDG y los manejadores de apps
preferidas del host. Hornero provee esas conexiones; el host decide qué
programa opcional se abre.

Para relaciones soportadas entre aplicaciones, estado de paquetes, rutas de
configuración y solución de problemas, usá el catálogo canónico
[Apps y flujos](../applications/README.md). Para comandos que inspeccionan o
cambian capacidades del escritorio, mirá [`horneroctl`](horneroctl.md).

Teclas rápidas: **Super + T** terminal, **Super + W** navegador, **Super + F**
archivos gráficos y **Super + E** gestor de archivos en terminal. Mirá la
[lista completa de atajos de teclado](shortcuts.md).
