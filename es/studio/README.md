# Studio y producción multimedia

Guías para grabar, producir y publicar demos, tutoriales y videos de vitrina
de HorneroOS de forma limpia sobre Wayland y PipeWire.

## Guías

- [Flujo de producción para YouTube y contenido](youtube-production-workflow.md)
  — Hornero Demo Studio, Modo Presentador, OBS Studio + PipeWire + Portales
  XDG Desktop, separación de bitrate, pistas de audio independientes sin
  auto-habilitar micrófono ni cámara, 10 escenarios listos para grabar y
  exportación a Kdenlive.
