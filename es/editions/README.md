# Ediciones

HorneroOS es una plataforma, no tres shells. Una **edición** agrega
capacidades (paquetes, diagnósticos, valores por defecto); un **modo de
experiencia** cambia cómo se comporta el escritorio ahora; un **layout** y
un **tema** cambian cómo se ve. Se componen: edición × modo × layout × tema
([arquitectura](../architecture/README.md),
[modos de experiencia](../desktop/experience-modes.md)).

- **Desktop**: Lema: Construí tu mundo; Madurez: Supported; Página:
  [Desktop](desktop.md)
- **Studio**: Lema: Hacé algo real; Madurez: Supported; Página:
  [Studio](studio.md)
- **Gaming**: Lema: Jugá a tu manera; Madurez: Supported, extras experimentales
  rotulados; Página: [Gaming](gaming.md)

Cada página separa **qué se verificó y dónde** de **qué no está validado**.
"Verificado" siempre nombra el lugar: CI, pruebas unitarias offscreen, la VM
de QA descartable o inspección de solo lectura de un equipo real. Nada de
esto es calificación de hardware, una afirmación de rendimiento ni de
compatibilidad con un juego o una aplicación.
