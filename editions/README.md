# Editions

HorneroOS is one platform, not three shells. An **edition** adds capabilities
(packages, diagnostics, defaults); an **experience mode** changes how the
desktop behaves right now; a **layout** and a **theme** change how it looks.
They compose: edition × mode × layout × theme
([architecture](../architecture/editions.md),
[experience modes](../desktop/experience-modes.md)).

- **Desktop**: Tagline: Build your world; Maturity: Supported; Page:
  [Desktop](desktop.md)
- **Studio**: Tagline: Make something real; Maturity: Supported; Page:
  [Studio](studio.md)
- **Gaming**: Tagline: Play on your terms; Maturity: Supported, experimental
  extras labelled; Page: [Gaming](gaming.md)

Each page separates **what was verified and where** from **what is not
validated**. "Verified" always names the place: CI, offscreen unit tests, the
disposable QA VM, or read-only inspection of a real host. Nothing here is
hardware qualification, a performance claim or a game/application
compatibility claim.
