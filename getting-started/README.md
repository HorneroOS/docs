# Getting started

## Know what is available

Hornero OS is in active development. The current project does **not** publish
an installable ISO or a supported whole-system installer. Development Preview
tags are tested compositions of project repositories, not ready-to-install
operating-system images. Check the [release ledger](https://github.com/HorneroOS/hornero/releases)
before installing or updating anything.

Individual components are packaged for people already running Arch Linux and
Hyprland. Those packages do not yet form a supported end-to-end installation
guide. Do not treat a package list, a dotfiles checkout, or an old wiki page as
an installer.

## Explore before installing

- See real product captures in the [Showroom](https://github.com/HorneroOS/website/tree/main/src/content/showroom).
- Compare the available [themes](https://github.com/HorneroOS/website/blob/main/src/pages/themes.astro)
  and [bar layouts](https://github.com/HorneroOS/website/blob/main/src/pages/layouts.astro).
- Read [desktop basics](../desktop/README.md), [shortcuts](../desktop/shortcuts.md),
  and [appearance](../desktop/appearance.md).

## When a supported installer is available

This page will become the installation guide only when the project publishes
a tested installation path. Until then, follow the release notes for changes
to package availability and use the project issue tracker for support on
development previews.
